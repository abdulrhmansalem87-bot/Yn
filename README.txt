خطوات التشغيل (مرة واحدة):
1) افتح الريبو بتاعك على GitHub (لازم يكون Public عشان رابط التحميل يشتغل لأي حد).
2) ارفع كل محتويات الفولدر ده في أول الريبو، بما فيهم فولدر .github (Add file > Upload files).
3) روح تبويب Actions وانتظر 5 لـ 8 دقايق لحد ما يخلص (علامة خضرا).
4) رابط التحميل: https://github.com/اسم-المستخدم/اسم-الريبو/releases/latest/download/waqfa.apk
بعد كده أي مرة ترفع waqfa-app.html معدّل، بيتعمل APK جديد أوتوماتيك على نفس الرابط.
لو فشل البناء: افتح الـRun الأحمر وابعتلي آخر 30 سطر من اللوج.
